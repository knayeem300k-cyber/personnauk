# Merchandiser

A browser-based apparel merchandising tool: buyers, product development, costing and BOM, sampling, orders, pre-production, production, quality, shipping and payments in one place.

## Run it
Open `index.html` in Chrome, Edge or Firefox. No installation or server is needed.

Online version (after GitHub Pages is turned on): https://knayeem300k-cyber.github.io/personnauk/

## Where data is saved
Everything you enter is saved in your own browser (localStorage), not in this repository.
Use **Export backup** in the sidebar to save a copy, and **Import backup** to load it on another computer or browser.

## Folders
- `index.html`: the page
- `css/`: design (`style.css`, `forms.css`, `ai-assistant.css`)
- `js/`: core logic (`store.js` data, `logic.js` rules, `components.js` UI parts, `export.js` Excel/PDF, `app.js` start-up)
- `js/pages/`: one file per module
